# Git commit rules

## Author attribution

- Use only the human owner's git identity (`Extrarius` / configured `user.email`).
- **Do not** add `Co-authored-by: Cursor <cursoragent@cursor.com>` or any Cursor/cursoragent co-author trailer.
- Cursor Agent must **not** appear in GitHub Contributors for this repository.

## Screenshots and local artifacts

- Do not commit screenshots (`.jpg`, `.png`, `.webp`, etc.) from the repo root or chat attachments.
- Store homework exports under `doc/` as Markdown only.
